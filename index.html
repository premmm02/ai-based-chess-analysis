How phase accuracy is calculated

Engine-estimated values

The report evaluates positions with the Lichess Cloud Eval service when an evaluation is available. Accuracy is estimated from centipawn loss; it is not an official Chess.com rating. Positions without a cloud evaluation are marked unrated instead of being assigned invented scores.

Analysis uses available engine evaluations. Missing evaluations are shown as unrated.
